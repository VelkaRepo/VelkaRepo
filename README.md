### On the workbench

#### [cmd-unmask](https://github.com/VelkaRepo/cmd-unmask)

Static command-line de-obfuscation and behavioral triage for SOC analysts and detection engineers. Unpacks common layers, pulls out behaviors and IOCs, and can write SOC notes or Sigma rules. It doesn't execute the command it analyzes.

```bash
git clone https://github.com/VelkaRepo/cmd-unmask.git
cd cmd-unmask
pip install -e .
cmd-unmask "suspicious_command_line"
```
